# Technical Orb Design Concepts (V3: Cyber-Tech Theme)

These designs leverage the existing SVG architecture but introduce more aggressive, high-tech motion patterns.

### Concept 5: The Scanner Node
This concept uses a horizontal light sweep to give it that "scanning" cyber-tech feel.
*   **Implementation:** A wide, horizontal neon-blue "blade" of light that pans back and forth across the orb. The central core pulses with audio intensity.
*   **Feel:** Clinical, precise, scanning-focused.

![Scanner Node](/src/assets/images/cyber_scanner_node_1792648556278.jpg)

### Concept 6: The Neural Spiral
This pushes the mechanical aperture look further, using a deep, swirling spiral shutter.
*   **Implementation:** Multiple curved SVG paths for the shutter blades that overlap. When Alpha thinks or speaks, these blades rapidly rotate into a tight spiral, then expand.
*   **Feel:** Complex, deeply technological, "living" mechanical eye.

![Neural Spiral](/src/assets/images/cyber_neural_spiral_1792648568077.jpg)
