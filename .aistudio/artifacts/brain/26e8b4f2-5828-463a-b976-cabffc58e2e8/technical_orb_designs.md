# Technical Orb Design Concepts

These concepts move away from a "sticker" look and embrace a purely code-driven, cyber-tech aesthetic that I can implement with 100% accuracy using SVG, CSS, and React.

### Concept 1: Refined Holographic Aperture
This evolves the current `CyberEye` by streamlining the mechanical look.
*   **Implementation:** Thinner, cleaner SVG paths for aperture panels, reduced visual noise, and smoothed `ease-in-out` CSS transitions for breathing animations to make it feel like it's "alive" rather than just a mechanical shutter.
*   **Feel:** High-fidelity, sharp, precise, yet organic in its rhythmic pulse.

![Refined Holographic Aperture](/src/assets/images/cyber_organic_aperture_refined_1792648187964.jpg)

### Concept 2: The Data Flux Node Sphere
This replaces the bezel with concentric, rotating data rings that react to state changes (thinking, speaking).
*   **Implementation:** Concentric SVG rings holding small nodes (circles). Each node's position and glow intensity will be calculated using math (Sine/Cosine) based on active state. It won't use complex ray-bursts but instead fluid, orbital motions.
*   **Feel:** Highly technical, dynamic, and reactive to Alpha's "neural activity."

![Data Flux Node Sphere](/src/assets/images/cyber_flux_nodes_1792648201415.jpg)

### Why these are accurate:
The current `CyberEye` is already built using SVG elements, React state (`analyser`, `speaking`, `active`), and CSS animations. I am proposing to *re-factor* this code, not add a new sticker.
